# يومي

تطبيق تنظيم الوقت والأهداف حسب الـPRD: "PRD - تطبيق تنظيم الوقت والأهداف (offline)".
عربي RTL، يشتغل بدون إنترنت، والبيانات على الجهاز فقط.

## الملفات

| الملف | شنو يسوي |
| --- | --- |
| `index.html` | التطبيق كامل (HTML + CSS + JS بدون مكتبات) |
| `sw.js` | يخزن الملفات حتى يشتغل بدون إنترنت. غيّر `VERSION` مع كل إصدار |
| `manifest.json` | يخلي التطبيق يتثبت على شاشة الموبايل |
| `icon.svg`, `icon-192.png`, `icon-512.png` | الأيقونات |

## التشغيل على الكمبيوتر

```
cd F:\claudy\yawmi
python -m http.server 5195
```

وافتح http://localhost:5195

## التثبيت على الموبايل

لازم ينرفع على https، لأن التثبيت والشغل بدون إنترنت ما يصيرون إذا فتحت الملف مباشرة.
أسهل طريقة مجانية: ارفع المجلد على Netlify Drop (اسحب المجلد على app.netlify.com/drop)، أو على GitHub Pages.

- **آيفون:** افتح الرابط بسفاري ← زر المشاركة ← "إضافة إلى الشاشة الرئيسية".
- **أندرويد:** افتح الرابط بكروم ← القائمة ← "تثبيت التطبيق".

بعدها: الإعدادات ← "صدّر ملف التقويم" ← أضفه لتقويم الموبايل حتى توصلك الإشعارات.
خلي التطبيق على موبايل واحد، لأن البيانات ما تنتقل بين الأجهزة إلا بملف JSON.

## اللي موجود (P0 من الـPRD)

- شاشة اليوم: البلوك الحالي بحلقة تقدم، التالي، النقاط، السلسلة، الأيام الباقية للنتيجة.
- ابدأ / 10 دقائق بس / أنجزت / تخطيت / اسحب لوقت ثاني، والوقت المرن يكمّل اللي فات.
- وضع التركيز بملء الشاشة مع Wake Lock، وصوت واهتزاز بالنهاية.
- النقاط: كامل 10، جزئي 4، البدء بوقته الأصلي +2.
- السلسلة: بلوكين أهداف باليوم (واحد بيوم أخف)، الجمعة ويوم سماح بالأسبوع ما يكسرونها.
- دورة الـ14 يوم: أهداف الكتاب والمشروع وكلاود، وقياسات الجيم، وشاشة نتيجة بالفرق والأسئلة الثلاثة، وسجل الدورات.
- تحرير الجدول، وتنبيه إذا تغيّر الجدول بعد آخر تصدير للتقويم.
- تسجيل النوم ومعدل 7 أيام، التقدم الأسبوعي، المشاريع بمهامها، والكتب.
- ملف تقويم .ics (أحداث متكررة مع تنبيه، وتذكير النوم، وتذكير يوم النتيجة).
- تصدير واستيراد JSON، وداكن/فاتح، وإيقاف الصوت والحركة.
